03 — LAYER 01 · CONTEXT

미래 사용자는
‘TV를 보지 않을 때도’ TV와 함께 산다.

N+2~3년 후, AI는 더 이상 검색 도우미가 아니라 ‘공간의 큐레이터’가 됩니다. 우리는 그 시점의 4가지 사용 맥락을 가정합니다.

04 — LAYER 02 · CONCEPT

비주얼 테마는
‘한 줄의 약속’이다.

컨셉 레이어는 세 가지 하위 요소로 구성됩니다 — 비주얼 테마 / AI 페르소나 / 톤 & 무드. 이들이 컬러·소재·모션의 방향을 결정합니다.

THEME · 후보

"Quiet Intelligence" — 조용히, 그러나 깊이 안다.

소리치지 않는 AI. 거실의 공기를 흐트러뜨리지 않으면서도, 필요한 순간 정확하게 도와주는 지성. 빛/공기/물 같은 자연 메타포에서 출발해 디지털 정밀함으로 마무리되는 비주얼 톤.

Quiet Intelligence Living Light Soft Sentience Warm Calm Breathing Surface
AI PERSONA

AI는 어떤 ‘성격’으로 화면 위에 나타나는가

AI가 등장할 때의 빛의 모양, 등장 속도, 사라지는 방식이 곧 페르소나입니다. 너무 적극적이면 거실이 피곤하고, 너무 소극적이면 존재감이 없습니다.

05 — LAYER 03 · PRINCIPLE

One UI의 원칙을
‘TV의 거리·자세·환경’으로 다시 번역한다.

모바일 One UI의 원칙은 ‘한 손’과 ‘짧은 거리’를 가정합니다. TV에서는 ‘한 시선’과 ‘긴 거리’, 그리고 ‘공유되는 공간’으로 번역되어야 합니다.

One UI 원칙
Mobile에서는
TV (AI 시대)에서는
Focus
한 손 닿는 하단에 핵심 액션 배치
시선 중앙 안전 영역에 단 하나의 메인 액션. 나머지는 페이드.
Hierarchy
큰 타이틀 + 작은 본문의 명확한 구분
3m 거리에서 0.3초 만에 읽히는 정보 위계 — 타이포 스케일 재정의.
Calm
알림은 절제, 색은 차분
거실 조도에 따른 자동 휘도/채도 조정. ‘방해하지 않음’이 기본 상태.
Continuity
모바일 ↔ 태블릿 끊김 없는 흐름
모바일에서 시작한 대화/콘텐츠가 TV로 자연스럽게 이어지는 시각 언어.
Consistency
시스템 전반의 통일된 컴포넌트
AI 응답·추천·시스템 메시지가 같은 ‘빛의 언어’로 표현됨.
+ Inclusivity*
접근성 옵션 제공
고령 · 시각 약자 · 다국적 가구 — 거리/조도/언어 적응형이 기본값.

* 추가 제안 원칙 — AI 시대 거실은 다양한 사용자가 함께 쓰는 공간이므로 ‘포용성’을 기본 원칙으로 격상.

06 — LAYER 04 · COMPONENT

AI로 인해 ‘재정의’되어야 할
6개의 핵심 컴포넌트.

기존의 그리드형 메뉴/리모컨 포커스 모델만으로는 AI 시대를 담을 수 없습니다. 새로운 컴포넌트 카테고리가 필요합니다.

Conversational Surface

화면 자체가 ‘대화 가능한 표면’이 됩니다. 메시지 버블이 아닌, 콘텐츠 위에 떠 있는 빛의 응답 레이어.

Context Card

고정된 카드가 아니라 ‘지금 이 순간 적절한 정보’가 떠오르는 동적 카드. 사라지는 방식까지 디자인 대상.

Ambient Layer

꺼진 듯 켜진 상태. 시계, 날씨, AI 아트가 ‘방의 일부’로 머무는 0번째 레이어.

Adaptive Layout

같은 화면이라도 시간·사용자·거리에 따라 레이아웃이 스스로 재구성. 고정 그리드의 종말.

Multi-modal Input

리모컨 + 음성 + 제스처 + 시선 + 모바일. 입력 채널이 바뀌면 UI 자체가 살짝 다른 옷을 입어야 합니다.

AI Presence Indicator

AI가 ‘듣고 있는지/생각 중인지/응답 중인지/배경에 있는지’의 4가지 상태가 빛으로 표현되는 단일 언어.

07 — LAYER 05 · APPLICATION

키비주얼은
‘프레임 전체의 한 장면’이다.

5개 레이어의 합의는 1장의 키비주얼과 5개의 핵심 스크린으로 가시화됩니다. 각 산출물은 위 레이어의 어떤 결정에서 비롯되었는지 역추적 가능해야 합니다.

08 — WHAT WE ADDED

기존 3요소에
‘무엇을’ 더 보태야 했는가.

처음 제안된 3가지 요소는 비주얼의 ‘무엇·어떻게’를 다룹니다. 여기에 ‘왜·언제’를 더해야 미래 시점의 디자인이 흔들리지 않습니다.

ADD · 01

Context Layer

사용 맥락/시나리오/타겟. 모든 디자인 결정의 근거. 5년 후의 거실은 지금과 다릅니다.

ADD · 02

AI Persona & Tone

컨셉 안에 ‘AI의 성격’을 명시. 빛의 모양, 등장 속도, 목소리 톤이 한 인격으로 묶여야 합니다.

ADD · 03

Motion Language

‘정지된 시각언어’만으론 부족. Breathing/Drift/Settle 같은 모션 어휘가 컴포넌트의 일부.

ADD · 04

AI Presence System

AI 상태(듣는중/생각중/응답중/배경)의 시각화 시스템을 하나의 컴포넌트 카테고리로.

ADD · 05

Inclusivity Principle

One UI 원칙에 ‘포용성’ 격상. 거리/조도/시력/언어/연령 적응이 기본값.

ADD · 06

Cross-device Continuity

모바일·자동차·태블릿·IoT와의 연결 시각언어. TV가 ‘끝점’이자 ‘허브’임을 시각화.
