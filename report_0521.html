H1 Spatial System · Macro
Living Light v13 · 16/24
Layered Composition
레이어드 컴포지션 — 4 레이어의 시각 위계와 컴포지션 원칙
"AI가 어디에 등장하는가 — Standby·Content·Companion·Immersion 4 레이어가 각자의 시각 문법을 가지며, 사용자 개입도에 따라 점층적으로 강화된다."
H1.1
Layer-1 Sanctuary
콘텐츠 보호 원칙
Layer 1은 AI가 침범하지 않는 baseline. 상위 레이어가 콘텐츠를 가리지 않도록 위치·크기·투명도를 제어하는 비침범 원칙 시스템.
Baseline · Non-intrusive
H1.2
Layer-2 Slide Panel
가장자리 슬라이드 패널
Layer 2는 화면 가장자리에서 슬라이드 인 하는 반투명 패널 형태. 시청 콘텐츠와 공존하며 부가 정보를 표면 위에 띄움.
Edge · Translucent
H1.3
Layer-3 Full Canvas
풀스크린 전면 캔버스
Layer 3는 사용자의 명시적 선택일 때만 풀스크린으로 전환. AI와 대화·큐레이션·창작이 일어나는 전면 캔버스.
Fullscreen · On-demand
H2 Spatial System · Micro
Living Light v13 · 17/24
Generative Layout
생성형 레이아웃 — 콘텐츠가 그리드를 만든다
"정해진 틀에 콘텐츠를 끼우지 않는다. 콘텐츠의 의미와 맥락으로부터 그리드 자체가 생성된다 — Layer 2/3 안에서 콘텐츠 배치는 AI가 결정한다."
H2.1
Semantic Grid
의미 가중 그리드
콘텐츠의 의미적 가중치(중요도·시의성·사용자 선호)에 따라 그리드 셀의 크기와 위치가 자동 조정되는 가변 그리드 시스템.
Weight · Auto-sizing
H2.2
Context-Driven Hierarchy
맥락 가변 위계
시청 상황(시간대·동석자·이전 시청 패턴)에 따라 동일 콘텐츠 풀이라도 위계가 재구성되는 시간 가변형 위계 구조.
Time · Persona · Re-rank
H2.3
Fluid Composition
유체 컴포지션
콘텐츠 개수·길이·종류에 따라 레이아웃이 신축적으로 재구성되는 유체형 컴포지션. 빈 자리 없이 인접 요소가 자연스럽게 흐름.
Elastic · No-gap
H3 Relationship System · Card
Living Light v13 · 18/24
Adaptive Card
관계 적응형 카드 — Agent·Commentator·Curator·Generator의 카드 시스템
"카드는 단일 형태가 아니다. 4가지 AI 관계(Agent·Commentator·Curator·Generator)에 따라 카드의 형태·밀도·경계가 달라진다."
H3.1
Relationship-Tuned Density
관계 적응형 밀도
관계마다 카드 정보 밀도가 다름. Agent는 단일 결과 1줄, Curator는 다중 옵션 그리드, Generator는 4-up variants, Commentator는 가장자리 글랜스.
Density · Per-relation
H3.2
Permeable Card
투과 카드
Layer 2↔3 진입 시 카드 경계가 흐려지거나 명확해짐. 낮은 개입은 배경에 스며들고, 높은 개입은 명확한 프레임으로 부각.
Edge · Permeability
H3.3
Stateful Card
상태 보존 카드
카드가 상호작용 이력에 따라 상태(접힘·확장·디밍·승격)를 유지. 액션 간 이동해도 정체성을 잃지 않고 그 상태에서 다시 시작.
Memory · Persist
H4 Relationship System · Cue
Living Light v13 · 19/24
Symbolic Cue
상징 큐 — AI가 지금 무엇을 하는지 명시적으로 신호하는 시스템
"AI의 행위는 보이지 않는다 — 그래서 명시적으로 신호해야 한다. 모션·매터리얼·빛만으로는 모호한 '지금 무엇을 하는가'를 전달하는 상징 요소."
H4.1
State Glyph
상태 글리프
AI의 현재 상태(듣는 중·생각 중·생성 중·완료·대기)를 표현하는 고유 글리프 시스템. 텍스트 라벨 없이 형태 자체로 상태를 인지.
State · Glyph
H4.2
Action Icon
행위 아이콘
AI가 수행하는 행위(검색·추천·생성·요약·예약·실행)별 아이콘 어휘. 모션 + 아이콘 조합으로 "지금 무슨 일이 일어나는지" 즉시 식별.
Action · Icon
H4.3
Persona Mark
페르소나 마크
Agent·Commentator·Curator·Generator 각 관계가 자신의 시각적 시그니처를 가짐. 어떤 관계의 AI와 상호작용 중인지 한눈에 인지.
Persona · Signature
H5 Surface · Material Vocabulary
Living Light v13 · 20/24
Living Material
살아있는 매터리얼 — 컨테이너와 콘텐츠는 서로 다른 매터리얼 어휘
"카드 컨테이너와 카드 안 콘텐츠는 서로 다른 매터리얼 어휘를 가진다. AI/TV 환경 특화 표면 시스템 — *블러는 Layer 깊이를 표현하는 핵심 변수*다."
H5.1
Variable Blur Glass
가변 블러 글래스 · 컨테이너
서리 유리 컨테이너. Light(5px)는 자막처럼 겹쳐 보이고, Medium(20px)은 카드는 분리되지만 뒤가 인지, Heavy(40px+)는 영상을 차단하며 전면 등장.
Container · Blur Depth
H5.2
Diffused Aurora
확산 오로라 · 컨테이너
가장자리 발광 컨테이너. OLED 강점 활용. 발광 색(블루·앰버·뉴트럴)과 강도가 4 Action을 시각적으로 구분.
Container · Edge Glow
H5.3
Adaptive Typography
가변 타이포그래피 · 콘텐츠
카드 안 텍스트가 매터리얼처럼 작동. 가변 폰트(weight·width·optical size)가 정보 위계·AI 확신도·시청 거리에 반응.
Content · Variable Font
H6 Layer-Specific · Standby (L0)
Living Light v13 · 21/24
Glanceable Surface
글랜서블 서피스 — 꺼진 화면도 정보가 살아있는 Layer 0 표면
"TV는 꺼져있는 시간이 더 많다. 스탠바이·파워세이빙 모드에서도 핵심 정보가 표면 위에 살아 있어야 한다 — Layer 0 Standby의 시각 어휘."
H6.1
Standby Glance
스탠바이 글랜스
TV가 꺼진 상태에서 저전력 디스플레이로 핵심 정보(시간·날씨·다음 일정·요약 카드) 노출. 시야 끝에서 흘끗 봐도 인지 가능한 정보 위계.
Low-power · Info-card
H6.2
Ambient Information
앰비언트 정보층
시청자 주의를 끌지 않는 주변광 수준의 정보 노출. 글로우의 색·세기로 정보 종류를 구분(파란빛=일정, 따뜻한빛=메시지).
Glow · Color-coded
H6.3
Wake on Approach
접근 감지 깨움
사용자 접근·시선 감지 시 정보 깊이가 단계적으로 증가. 멀리서는 글로우, 가까이 가면 텍스트, 응시하면 상세.
Proximity · Progressive
H7 Layer-Specific · Companion (L2)
Living Light v13 · 22/24
Edge Ambient
엣지 앰비언트 — Layer 2 Companion의 시청 침범 최소화 어휘
"Layer 2 Companion은 화면 가장자리에 머문다 — 저채도의 앰비언트 어휘로 시청 침범 없이 AI의 존재감을 신호한다."
H7.1
Edge Band
가장자리 띠
화면 가장자리에 얇은 띠 형태로 AI의 상태(듣는 중·생각 중·완료)를 표현. 가장 보수적이고 시청 침범 없는 신호.
Frame · Low-saturation
H7.2
Ambient Hue Shift
분위기 색조 전환
화면 전체 또는 특정 영역의 색온도·채도가 미세하게 변화하며 AI 모드 전환을 암시. 명시적 UI 없이 분위기로 신호.
Tone · Implicit
H7.3
Spotlight Dimming
역방향 강조
특정 콘텐츠 영역만 밝게, 나머지는 디밍하는 역방향 강조. 영화 시청 중 AI가 추천할 때 추천 카드만 살아남는 연출.
Focus · Dim-around
H8 Layer-Specific · Immersion (L3)
Living Light v13 · 23/24
Generative Motion
생성형 모션 — Layer 3 Immersion · Generator의 시네마틱 시퀀스
"Layer 3에서 Generator가 일할 때, 생성 과정 자체가 시청 가치를 갖는 모션 시퀀스가 된다. 단순 로딩 스피너로 처리하지 않는다."
H8.1
Generation Sequence
생성 시퀀스
노이즈→형태→디테일→완성으로 이어지는 AI 생성의 단계 전환을 시네마틱한 시퀀스로 연출하는 모션 어휘.
Noise · Form · Detail
H8.2
Process Visualization
프로세스 시각화
프롬프트 단어·데이터·노드가 흐르고 결합되는 과정 자체를 보여주는 시각화. AI의 '일하는 모습'을 비주얼로 인지.
Data-flow · Node-graph
H8.3
Reveal Choreography
리빌 안무
최종 결과물 등장 방식이 안무처럼 의도된 연출. 4-up variants 동시 펼침, 순차 등장, 회전 등장 등 공개의 연출 문법.
Reveal · Choreographed
H9 ⚡ Meta · Conclusion
Living Light v13 · 24/24
Continuous Flow
컨티뉴어스 플로우 — 모든 가설을 관통하는 흐름 원칙
"AI 개입의 흐름은 끊기지 않는다 — 큰 전환 없이 하나의 연속체로 이어진다. 8개 가설을 통합하는 메타 원칙이자, 비주얼 디자인의 OS다."
H9.1
Morph Over Replace
변형 우선 원칙
요소가 사라지고 새 요소가 등장하지 않는다 — 기존 요소가 다른 형태로 변형된다. 추천 → 상세 → 결제 카드가 같은 요소의 모핑.
Transform · Not-replace
H9.2
Layer Bridge
레이어 브리지
Layer 2 ↔ Layer 3 전환이 끊김 없는 확장으로. 반투명 패널이 풀스크린으로 자연스럽게 확장되고 다시 가장자리로 회수.
L2 ↔ L3 · Seamless
H9.3
Action Handoff
액션 핸드오프
Commentator → Curator → Generator → Agent로 액션 전환 시, 같은 요소가 역할을 인계받음. 사용자 의도의 흐름과 동기화.
Action · Handoff
